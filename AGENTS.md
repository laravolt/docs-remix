# Laravolt Docs Agent Guide

Remix v3 port of the Laravolt documentation site (Tailwind Plus "Syntax" template, originally Next.js 15 App Router + Markdoc). Use these conventions when continuing to build it out.

## Commands

```sh
npm i
npm run dev        # NODE_ENV=development node --watch --import remix/node-tsx server.ts (port 44120)
npm run start
npm run typecheck
npm run css        # Tailwind CLI -> public/styles.css
```

Non-interactive shells break nvm — use absolute node paths, e.g. `$HOME/.nvm/versions/node/v22.22.2/bin/node`.

## Building Features

Refer to ./.agents/skills/remix/SKILL.md — Remix 3 has NO React and NO hooks. Components are `function X(handle: Handle<Props>)` returning a render function; imports come from the single `remix` package via subpaths.

## Layout

- `app/routes.ts` defines the route contract (home + every docs page)
- `app/router.ts` wires routes to route handlers
- `app/actions/controller.tsx` owns the top-level route actions
- `app/middleware/render.tsx` installs the request-scoped renderer
- `app/lib/markdoc.ts` — server-side Markdoc pipeline: parse/validate/transform `content/**/page.md` at request time
- `app/ui/markdoc.tsx` — renders the Markdoc RenderableTree to Remix elements (fence/code, callout, quick-links, etc.)
- `app/ui/` holds the document shell, layout, nav sidebar, prose styles
- `app/assets/entry.ts` + `theme.ts` — client entry and dark mode
- `content/` — the `page.md` sources copied from the Next.js repo (71 pages: home + v6 + v7)
- `public/` — static files; `public/styles.css` is generated by the Tailwind CLI

## URLs

The current version (v7) is served from the URL **root** — `/getting-started/installation`,
not `/v7/getting-started/installation`. Only legacy versions keep a prefix (`/v6/...`).

- `app/lib/markdoc.ts` maps a request path back to the content tree: anything
  that is not `/v6*` gets `/v7` prepended, so `content/v7/` stays on disk.
- `app/actions/controller.tsx` 301-redirects any leftover `/v7/*` URL (including
  `.md` mirrors) to its root equivalent; `scripts/prerender.ts` writes the same
  rules into `dist/_redirects` for the static deploy.
- Nav hrefs in `app/lib/navigation.ts` are unprefixed for v7 (`pathPrefix: ''`).

When adding a v7 page, link to it without the version prefix.

## Deploy

Production is `laravolt.dev`, a Cloudflare Worker named `laravolt-docs` serving
the **prerendered** site as static assets — not the Node server in `server.ts`,
which only runs locally and during prerender.

```sh
npm run build     # css + prerender -> dist/ (70 pages, .md mirrors, llms.txt)
npm run deploy    # build, then wrangler deploy
```

`dist/` is generated and gitignored; never edit it by hand. `wrangler.jsonc`
points at `./dist` with `not_found_handling: 404-page`.

## Branding

The Syntax template ships sky/cyan accents; Laravolt's identity is the purple
bolt from the legacy Jigsaw docs (`laravolt/laravolt.github.io`).

- Use the `brand-*` scale defined in `app/styles/tailwind.css` for every accent.
  Never reintroduce `sky-*`/`cyan-*`. `brand-500` (`#b263d1`) and `brand-800`
  (`#462eb4`) are sampled from the logo gradient; the rest is OKLCH-interpolated.
- Contrast: on white use `brand-600`/`brand-700` for text, on `slate-900` use
  `brand-300`/`brand-400`. `brand-500` only clears AA-large on white.
- `Logomark` in `app/ui/layout.tsx` is the logo, inlined as SVG — the bolt path
  is traced from the original `logo.png`. The wordmark next to it is plain HTML
  text so it inherits the site font and dark-mode color.

## Content Rules

- Do NOT hand-convert markdown to JSX. Add or edit pages by editing `content/**/page.md`; routes are derived from the content tree.
- `@markdoc/markdoc` is CJS: under Node ESM only the default export carries runtime values. Import `Markdoc` default and destructure (`const { Tag } = Markdoc`); named imports are fine for types only.
